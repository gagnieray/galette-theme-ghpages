{%- comment -%} The compatibility pill under one download link: which Galette generation that build targets, and whether it is the Galette anyone would install today. {% include requires.html label='1.2' rank=1002000 %} green, or red {% include requires.html label='nightly' %} neutral, no verdict `rank` is the build's own compatibility version packed into an integer, because Liquid cannot compare versions. Plugins::register() disables a plugin whose compver is LOWER than the running Galette's GALETTE_COMPAT_VERSION, and imposes no upper bound — so a build is compatible exactly when its rank reaches the one galette-version.html carries. Omitting `rank` asks for no verdict. That is what the nightly link needs — it targets whatever `develop` declares, against a Galette nightly nothing tracks — and it is also what an unverified `plugin.min_galette` gets: a number nobody read or compared is shown, not judged. Both numbers are substituted after translation, so neither enters a translatable string: the pill names the generation this build targets, and the title of the red one names the Galette it is behind. Expects the strings from i18n.html, and galette_version / galette_compat_rank from galette-version.html, to be in scope. The spans are written on one line each on purpose: Liquid would otherwise leave the indentation inside them, which an inline-flex box turns into a visible gap. {%- endcomment -%} {%- if include.label -%} {%- assign compat_text = t_compat_galette | replace: '%s', include.label -%} {%- capture tick -%}{%- endcapture -%} {%- capture cross -%}{%- endcapture -%} {%- if include.rank == nil -%} {{ compat_text }} {%- elsif include.rank >= galette_compat_rank -%} {{ tick }}{{ compat_text }} {%- else -%} {{ cross }}{{ compat_text }} {%- endif -%} {%- endif -%}
