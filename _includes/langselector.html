Native HTML, so it opens with the keyboard and works with JavaScript disabled; scripts.html only adds closing on Escape or an outside click. With nineteen languages in the project, a flat inline list would take the whole header. Pages of a same logical page share a `ref` and differ by their `lang`, which the consuming site sets through path-scoped `defaults` — so Weblate never has to write that key itself. Two guards, both learned from a real site: a page without `ref` has no translations by definition, and `where: 'ref', nil` would otherwise match every other ref-less page; and a language is listed once even when several pages claim it, which is what a README.md rendered as the index alongside an index.md does. {%- endcomment -%} {%- assign cur_ref = page.ref | default: '' -%} {%- if cur_ref != '' -%} {%- assign siblings = site.pages | where: 'ref', cur_ref | sort: 'lang' -%} {%- assign distinct = '' -%} {%- for sibling in siblings -%} {%- assign sl = sibling.lang | default: 'en' -%} {%- assign marker = '|' | append: sl | append: '|' -%} {%- unless distinct contains marker -%} {%- assign distinct = distinct | append: marker -%} {%- endunless -%} {%- endfor -%} {%- assign distinct_count = distinct | split: '||' | size -%} {%- if distinct_count > 1 -%} {%- include lang-name.html lang=cur_lang -%} {%- assign current_name = lang_name -%}
